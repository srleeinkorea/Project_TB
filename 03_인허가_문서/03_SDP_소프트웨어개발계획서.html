1. 목적과 적용범위

본 계획은 TB AI 시스템의 데이터 전처리, 모델 학습·검증, 추론, Heatmap·Probability Score 출력, SDK/API, Docker 기반 재학습 환경과 관련 문서에 적용합니다. 판독 UI 및 운영관리 시스템 신규 개발은 범위에서 제외합니다.

2. 개발 생명주기와 게이트

게이트단계필수 입력주요 출력완료 기준승인
G0착수 승인사업계획, 계약, DRFDMM, 역할·일정 기준선범위·책임·선행결정 승인대표이사
G1설계입력 기준선MRS, CRD, RRS, 데이터·레이블 입력SRS, RMP, UPL, RTM검증 가능하고 상충 없는 요구사항연구소장
G2데이터 잠금DMP/LBL, 익명화·QC 기록학습·검증·독립시험 데이터 잠금기록환자 중복 없음, 참조표준·분포 승인연구소장 + 협회
G3설계·모델 동결SAD, SDS, 실험기록, SBOM/SOTS동결 모델·코드·가중치·환경검증 대상 식별자와 임계값 고정연구소장
G4설계 검증 완료SVEP, SUT/SIT/SST 계획SVER, PRR, 결함·잔여위험요구사항·위험통제 검증 및 결함처리연구소장
G5유효성 확인SAP/SVAP, 잠금 시험세트SVAR, 사용성·임상근거사전 기준에 따른 독립 평가 완료연구소장
G6인허가 제출준비TD/RSD, RMR, IFU, V&V제출본·보완대응 기록적용성 체크·QMS·제출자료 승인대표이사
G7완료·이관최종 코드·가중치·Docker·문서DDR/DCR, 재현·이관 확인서협회 환경 재현·교육·인수 승인대표이사 + 협회

4. 개발 방법과 주요 기록

REQUIREMENTS검증 가능하게 작성

MRS/RRS/CRD를 SRS 항목으로 분해하고 고유 ID, 근거, 우선순위, 수용기준, 시험 연결을 유지합니다.

DATA환자 단위 분할·잠금

학습·검증·독립시험 간 환자·검사 중복을 방지하고 데이터 선정·제외·익명화·레이블 변경 이력을 보존합니다.

MODEL실험과 동결 분리

실험 ID, 코드 커밋, 데이터 버전, 시드, 하이퍼파라미터, 라이브러리, 지표를 기록한 뒤 검증 모델을 동결합니다.

TEST계획 선승인

시험 목적·입력·절차·예상결과·수용기준을 실행 전에 승인하고 결함·재시험·일탈을 기록합니다.

형상항목최소 식별정보변경 시 필수 영향평가
