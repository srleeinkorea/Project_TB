1. 목적과 원칙

모델·임계값·통계계획·독립시험 데이터를 실행 전에 동결하고, 사전 승인된 분석만으로 성능을 판정합니다. 본 문서는 통계 골격이며 표본수·가설·신뢰구간·합격기준은 통계전문가와 규제상담 후 확정합니다.

2. 시험 독립성

통제요구증빙
시험 데이터학습·튜닝에 사용되지 않은 환자단위 잠금 세트, 가능하면 기관·시점 외부성 확보데이터 잠금기록·중복검사·분포표
모델코드·가중치·임계값·전처리·Docker digest 고정G3 동결 기록·해시
분석계획대상군·참조표준·지표·CI·하위군·결측·일탈·합격기준 선승인SAP 승인본
접근권한개발팀은 시험 레이블·중간결과로 모델을 수정하지 않음권한대장·감사로그
일탈사후 제외·재분석은 사유·영향·승인을 기록하고 원분석도 보존일탈·변경·분석 로그

3. 통계분석 계획 골격

항목초안확정 필요
분석단위환자/검사 단위 1개 결과반복 촬영·다중 영상 처리
주 분석대상결핵 의심 양성 대 비결핵 음성의 선별 성능활동성·비활동성 포함 방식
주 지표민감도, 특이도와 95% 신뢰구간정확한 CI 방법·합격판정
부 지표AUC, FP/FN, PPV/NPV, 클래스별 지표유병률 보정·다중성

표본수양성·음성 각각 목표 정밀도/검정력 기반 산출가설, 유의수준, 탈락률
하위군연령·성별·기관·장비·촬영방식·클래스확증/탐색 구분·최소수
결측·판독불가사전 정의된 사유코드와 주/민감도 분석실패결과의 보수적 처리
참조표준전문의 판독과 가용 확진·임상근거 조합판독자 수·중재·시간창
표본수와 합격기준 없이 독립시험을 시작하지 않습니다. 5,000건은 전체 개발 데이터 목표이며 독립시험의 통계적 충분성을 자동으로 의미하지 않습니다.

4. 결과 보고 최소 항목

  • 대상 흐름도: 후보·선정·제외·최종 분석 수와 사유
