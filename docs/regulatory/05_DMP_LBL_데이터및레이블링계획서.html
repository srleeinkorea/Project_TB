1. 데이터 범위와 원칙

대한결핵협회가 적법하게 보유하고 승인된 범위에서 추출한 흉부 X-ray와 판독·검사 정보를 사용합니다. 개발사는 계약 목적에 한해 처리하며, 데이터와 파생데이터의 권리는 협회에 귀속됩니다.

TARGETCXR 약 5,000건

활동성 결핵·비활동성 결핵·정상군. 기타 폐질환군은 별도 결정.

IDENTITY환자 단위 관리

동일 환자의 반복 촬영이 서로 다른 분할에 포함되지 않도록 고유 연구키로 통제.

PRIVACY비가역적 익명화 원칙

DICOM·영상 내 식별정보를 제거하고 원본 연결 가능성을 차단.

4. 데이터 분할·잠금

  1. 환자 단위로 학습·튜닝용 검증·독립시험 세트를 분리합니다.
  2. 동일 환자, 동일 검사, 파생 이미지가 다른 세트에 중복되지 않도록 해시·연구키로 확인합니다.
  3. 클래스·연령·성별·기관·장비 분포를 비교하고 차이를 문서화합니다.
  4. 독립시험 세트는 개발팀이 레이블·결과를 볼 수 없도록 접근을 분리합니다.
  5. 잠금 후 변경은 변경요청, 근거, 영향평가, 재잠금 승인과 새 버전으로만 수행합니다.
분할 비율과 클래스별 사례 수는 SAP의 표본수 계산 후 확정합니다. 임의의 70/15/15 비율을 기준값으로 고정하지 않습니다.

5. 보안·보존·파기

  • 승인된 저장소, 최소권한, 승인 IP, 전송·저장 암호화, 접근·반출 로그를 적용합니다.
  • 개인 PC·개인 클라우드·이메일·외부 저장매체로 임의 반출하지 않습니다.
  • 유출·무단접근·훼손 의심 시 즉시 이용을 중지하고 개발사·협회 책임자에게 보고합니다.
  • 연구 완료 또는 계약 해지 후 5일 이내 복구 불가능하게 파기하고 파기확약서를 제출합니다.
  • 인허가 유지에 법정 보존이 필요한 경우 대상·근거를 서면 통보하고 외부망 차단 암호화 저장소에 격리합니다.
