2026.10.01 데이터 제공 범위 협의

계약 체결(2026.08) 이후 실제 제공 가능한 데이터의 범위와 구성을 확인한 대면회의.

구분내용
일시2026.10.01 · 대면회의
참석대한결핵협회 정보화운영팀 / 마이허브 의학전략실
안건제공 가능 CXR 규모, 미생물학적 확진 데이터 규모, 영상과 검사 결과의 연결 가능성, 다기관·다장비 데이터 구성, 부분 데이터 활용

확인된 사실

항목확인 내용
전체 CXR20,000장 이상 제공 가능. 영상 품질·중복·익명화·레이블 검수 전 규모임.
배양검사 양성 확진 데이터약 400건. 추가 확보는 현실적으로 어려운 것으로 확인됨. 확진 400건은 20,000장에 포함되는 수치임.
영상과 확진 결과의 연결복십자의원은 결핵 의심 환자의 추적관찰을 수행하지 않아, 의심 소견 이후의 검사 결과를 영상에 연결하는 데 구조적 제약이 있음.
판독 소견 기반 데이터20,000장 범위 안에서 구성 가능하며, 활용 목적은 별도 검토가 필요함.
다기관·다장비 데이터충분한 확보 근거가 확인되지 않음.
약 5,000장 활용안논의되었으나 성격(확정 제공분인지, 전체 중 특정 분류군인지)은 확인되지 않음.

논의 요지

  • 초기 협의는 대규모 CXR 제공과 전문의 레이블링을 중심으로 진행되었고, 이후 의료기기 제품화·인허가 요건을 구체화하는 과정에서 확진 데이터와 다기관·다장비 자료의 필요성이 명확해짐. 회의에서는 이 변화를 양 기관이 함께 확인함.
  • 이는 어느 한쪽의 이행 부족이 아니라, 연구 초기의 데이터 활용 전제와 이후 구체화된 개발·검증 요건 사이의 차이로 정리함.
  • 판독 소견 기반 데이터는 영상 소견 학습에 활용할 수 있으나, 활동성 결핵 성능 입증의 참조표준으로는 성격이 다르다는 점을 공유함.
