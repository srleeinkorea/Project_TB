2026.10 온라인 협의

데이터 제공 범위 확인(2026.10.01) 이후, 학습·검증 데이터의 기준과 추진 방식에 대해 양 기관이 온라인으로 협의한 회의. 공유 가능한 범위에서 확인된 사실과 양측 입장, 합의 사항만 정리하며 참석자는 기관·역할 단위로 표기함.

02

확인된 사실

항목확인 내용
배양 양성 확진 데이터2026.08까지 약 5~6년치 배양검사 양성 약 400건. 협회 검진 영상과 검사 결과를 수작업으로 대조해 확보한 수치이며, 추가 확보는 어려움. 협회는 외부 의뢰 검진의 사후 검사 결과를 보유하지 않고, 복십자의원 내원자만 검사 결과까지 연결됨.
영상 매수협회 보유 영상은 약 700만 장 규모이며, 연구용 제공은 2만 장 이상으로 확대 가능함. IRB 승인은 2만 장 이상이 필요할 수 있다는 전제로 받음.
학습 데이터의 기준협회는 학습용 라벨을 판독 소견(유소견·정상) 기준으로 제공할 수 있으며, 확진 결과 기준 라벨은 400건 외에는 제공이 어려움.
DICOM 메타데이터개인정보 심의위원회에서 익명 정보로 확정한 항목(영상, 판독 분류, 연령대) 외의 태그 추가 제공은 재심의가 필요하여 현실적으로 어려움. 협회는 수탁자 지위로 익명정보만 사용할 수 있음.
진단 절차검진 촬영 → 판독(유소견자 선별) → 객담 검사(배양·분자검사) → 균 동정 → 확진. 배양검사는 살아 있는 결핵균을 분리·동정하는 확진 검사이며, 분자검사(Xpert 등)는 결핵 검출과 리팜피신 내성 여부를 동시에 확인함. 분자검사만으로 활동성·비활동성은 구분되지 않음.
WHO 기준WHO는 AI 모델의 최초 학습 데이터 수량을 별도로 규정하지 않음. 임상 성능 평가는 학습에 사용하지 않은 별도 데이터셋, 대상 인구·장비 다양성, 미생물학적 기준, 통계적으로 타당한 표본 규모를 요구함. 협회가 제시한 평가 규모(양성 260건·음성 2,500건)의 출처는 추후 확인함.
03

양측 입장

대한결핵협회
  • AI의 역할은 검사를 받아야 할 사람을 선별하는 판독 단계까지이며, 검사 결과를 예측하는 것은 AI의 역할이 아님.
  • 판독 소견 기준으로 학습하고, 400건의 확진 데이터는 학습에 쓰지 않고 임상 검증용으로 활용하면 모델 개발이 가능함.
  • 협회가 제공할 수 있는 데이터는 협회 내부 데이터로 한정됨. 다기관·해외 데이터 확보는 1차 모델 이후 마이허브가 별도로 추진할 영역이며, 계약상 2차 산출물은 각자 관여하지 않기로 되어 있음.
  • 사업 중단보다 단계적 추진(초기 모델 → 독립 시험셋 검증 → 다기관·다장비 확대 → WHO 평가)을 제안함.
  • 국내 인허가는 큰 어려움이 없을 것으로 판단함.
마이허브
  • 판독 소견 기준 모델은 개발 가능하며 협회 내부 사용 목적에는 문제가 없음. 다만 WHO CAD 평가와 해외 기준은 확진 환자를 기준으로 성능을 평가하므로, 확진 환자 데이터가 충분히 포함된 학습이 필요함.
  • 단일 기관 데이터로 학습한 모델은 외부 기관에서 성능이 낮아지는 사례가 많음. 400건까지의 내부 검증은 1차 관문이며, 외부 검증이 있어야 범용성이 입증됨.
  • 국내 인허가는 기허가 제품과 동등한 수준의 성능 설계가 요구되므로, 인허가 목표 기준으로 역산한 학습·검증 데이터 규모를 제안한 것임.
  • 개발 목표가 협회 내부용 모델인지, WHO 기준을 충족하는 모델인지 명확히 할 필요가 있음.

양측은 판독 소견 기준 모델의 개발 가능성에는 의견이 같았고, 그 모델이 WHO·해외 기준과 당초 목표를 충족하는지에 대해서는 의견 차이가 있음을 확인함.
