2025.12.11 공동개발 추진 협의

결핵 X-ray AI 모델 공동개발의 방향, 데이터 제공과 임상·인허가 고려사항, 협업 역할을 처음 논의한 회의.

구분내용
일시 · 장소2025.12.11 · 대한결핵협회 대회의실
참석대한결핵협회 정보화운영팀·검진사업팀 / 마이허브 경영진·기술·PM
안건기존 CXR AI 활용 현황, 활동성·비활동성 결핵 판별 모델 개발 방향, 데이터 제공 범위와 전처리, 레이블링·학습 전략, 임상시험·인허가, 역할 분담

논의 요지

  • 협회는 기존 CXR AI를 검진 현장에서 사용 중이며, 휴대용·저선량 촬영 환경에서의 성능 변동과 유소견 판정 분포의 차이를 현장 경험으로 공유하였다.
  • 양 기관은 결핵에 특화된 모델의 개발 필요성에 공감하였다. 기허가 제품의 학습 데이터 규모와 동일한 수준의 데이터 확보는 현실적으로 어렵다는 점도 함께 확인하였다.
  • 레이블링 방식(분류·병변 표시·세그멘테이션)은 학습 전략에 따라 달라지므로, 데이터를 먼저 확인한 뒤 구체 설계하기로 하였다. 병변이 작고 경계가 불명확한 경우가 있어 영상만으로는 난이도가 있다는 점을 공유하였다.
  • 결핵 양성의 정의와 관련하여 도말 음성·배양 양성 등 확진 경로가 다양하므로, 라벨 정의(확진 기준)가 중요하다는 점을 확인하였다.
  • 임상시험계획과 식약처 인허가 요구사항은 모델 개발과 병행하여 초기부터 고려하기로 하였다.
  • 데이터는 DICOM으로 제공 가능하며, 기관명 등 식별정보는 제거 후 제공하는 방향으로 확인하였다.
  • 협회의 파인튜닝은 연구 목적 범위를 전제로 하며, 의료기기 제조자로서의 모델 관리 책임은 마이허브에 있음을 확인하였다.

2026.10.01 데이터 제공 범위 협의

계약 체결(2026.08) 이후 실제 제공 가능한 데이터의 범위와 구성을 확인한 대면회의.

구분내용
일시2026.10.01 · 대면회의
참석대한결핵협회 정보화운영팀 / 마이허브 의학전략실
안건제공 가능 CXR 규모, 미생물학적 확진 데이터 규모, 영상과 검사 결과의 연결 가능성, 다기관·다장비 데이터 구성, 부분 데이터 활용

확인된 사실

항목확인 내용
전체 CXR20,000장 이상 제공 가능. 영상 품질·중복·익명화·레이블 검수 전 규모이다.
배양검사 양성 확진 데이터약 400건. 추가 확보는 현실적으로 어려운 것으로 확인되었다. 확진 400건은 20,000장에 포함되는 수치이다.
영상과 확진 결과의 연결복십자의원은 결핵 의심 환자의 추적관찰을 수행하지 않아, 의심 소견 이후의 검사 결과를 영상에 연결하는 데 구조적 제약이 있다.
판독 소견 기반 데이터20,000장 범위 안에서 구성 가능하며, 활용 목적은 별도 검토가 필요하다.
다기관·다장비 데이터충분한 확보 근거가 확인되지 않았다.
약 5,000장 활용안논의되었으나 성격(확정 제공분인지, 전체 중 특정 분류군인지)은 확인되지 않았다.

논의 요지

  • 초기 협의는 대규모 CXR 제공과 전문의 레이블링을 중심으로 진행되었고, 이후 의료기기 제품화·인허가 요건을 구체화하는 과정에서 확진 데이터와 다기관·다장비 자료의 필요성이 명확해졌다. 회의에서는 이 변화를 양 기관이 함께 확인하였다.
  • 이는 어느 한쪽의 이행 부족이 아니라, 연구 초기의 데이터 활용 전제와 이후 구체화된 개발·검증 요건 사이의 차이로 정리하였다.
  • 판독 소견 기반 데이터는 영상 소견 학습에 활용할 수 있으나, 활동성 결핵 성능 입증의 참조표준으로는 성격이 다르다는 점을 공유하였다.
