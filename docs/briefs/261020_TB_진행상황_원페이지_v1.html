추가 데이터 확보를 전제로 공동연구 지속 추진

10월 15일 협의에서 해외·국내 추가 데이터로 연구 범위를 보완하는 방향에 합의함. 국가별 확보 규모·일정·제공 가능 범위를 확인한 후 AI 개발과 임상·인허가 계획을 구체화할 예정임.

계속 추진 합의는 확인됨. 추가 데이터의 실제 수령, 전체 레이블링 및 모델 학습 완료 여부는 미확인임.

지금 어디까지 왔나

  1. 준비 진행연구·도구 준비

    연구 수행 준비와 레이블링 도구 개발이 진행됨.

  2. 현재데이터 확보 계획

    추가 제공량·확진 매칭·국가별 일정을 확인함.

  3. 후속 계획구축·레이블링·학습

    제공 조건과 판정 기준을 반영해 실행 계획을 정함.

  4. 후속 계획독립 검증·인허가

    확보 데이터에 맞춰 평가·인허가 로드맵을 구체화함.

주요 경과

  1. 6~8월연구 수행 준비 및 레이블링 도구 개발을 진행함.
  2. 9월 4일실무 킥오프에서 데이터 구성·판정·전달 조건을 협의함.
  3. 9월~10월 초확진 데이터 규모와 기관·장비 다양성 보완 필요성을 검토함.
  4. 10월 15일해외·국내 추가 데이터를 활용하여 공동연구를 계속 추진하기로 합의함.
  5. 10월 20일주간보고에 데이터 확보 계획 확인 후 개발·임상·인허가 계획 구체화 예정으로 기록됨.
