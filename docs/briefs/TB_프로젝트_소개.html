PROJECT OVERVIEW

프로젝트가 해결하려는 문제

단순한 모델 개발을 넘어, 데이터의 신뢰성부터 검증·인허가·기술내재화까지 하나의 관리체계로 연결합니다.

PROJECT PURPOSE

일관된 결핵 영상분석을 지원하고, 협회가 재현·검증·개선할 수 있는 AI 기술 기반을 확보합니다.

모델 성능뿐 아니라 데이터 추적성, 전문의 판독 기준, 재현 가능한 개발환경, 규제 문서와 변경관리 체계를 함께 구축합니다.

의료진 대체가 아닌 진단보조최종 판단은 의료진이 수행하며 AI 결과의 한계와 실패조건을 명확히 표시합니다.
연구 모델과 허가 모델 분리재학습 모델은 허가 버전과 별도로 관리하고 배포 전 규제영향평가를 수행합니다.
독립 검증 우선학습에 사용되지 않은 잠금 시험세트로 민감도·특이도·AUC와 신뢰구간을 평가합니다.

착수 단계에서 확정할 사항

아래 결정이 미완료된 경우 관련 단계 게이트를 완료 처리하지 않습니다.

긴급전체 일정 기준선연구 종료 2029.06과 계약 종료 2028.12.31을 분리하고, 필요 시 계약 연장 시점을 사전 확정합니다.
긴급레이블·레퍼런스 표준판독자 수, 불일치 중재, 근거자료, 모호사례 처리와 전문의 최종책임을 정합니다.
긴급독립 검증 통계기준표본수, 95% 신뢰구간, 합격판정, 결측·하위군 처리계획을 시험 전에 동결합니다.
긴급IP·ODA 사용범위공동산출물, 상업권, 제3자 제공·재허락, 배경IP와 공통모듈의 경계를 부속합의로 정리합니다.
높음허가모델·재학습모델승인 버전과 협회 개선 버전을 분리하고, 재학습·배포 전 규제영향평가 절차를 둡니다.
높음인허가 제출자료고정된 ‘26종’이 아닌 제품 등급·심사경로별 적용성 체크리스트로 RA·MFDS 사전상담 후 확정합니다.
