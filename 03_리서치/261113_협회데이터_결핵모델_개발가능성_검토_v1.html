협회 데이터로 결핵 AI 모델을 실제로 개발할 수 있는가

협회 보유 약 7백만 건의 흉부 X-ray 판독코드 집계(결핵 관련 14개 코드 4,835건)를 국내외 결핵 AI 연구 · 제품의 학습 데이터 규모와 비교하고, 모델 유형별 개발 가능성과 착수 조건을 정리함.

결핵 관련 판독 4,835건그 외 7,872,235건배양 확진 약 400건단일 출처판독코드 중복 여부 미확인
검토 결론
  1. 결핵 의심 영상 소견 검출 모델은 개발 가능함. 결핵 양성 4,835건은 외부 검증에 성공한 국내 대표 연구(6,768장)의 71%, 외부에서 성능이 떨어진 연구(3,824장)보다 많은 규모이며, 음성 데이터는 충분함.
  2. 다만 데이터 규모보다 다양성 · 라벨 품질이 성패를 가름. 비교 연구들에서 외부 성능을 지킨 쪽은 다기관 · 다국가 데이터와 외부 검증을 갖춘 경우였음. 협회 데이터는 단일 출처라 별도 기관의 외부 검증 데이터가 반드시 필요함.
  3. 확진 기준 활동성 결핵 선별(WHO 기준)은 현재 데이터로 어려움. 확진 400건은 미생물 확진 기준 연구들의 시험셋 규모(수백~1천 명대)와 비슷해, 학습까지 감당하지 못함.

02규모보다 다양성이 외부 성능을 결정함비교 연구에서 확인되는 경향

단일 · 소수 기관, 내부 평가

1천 장 내외

Lakhani 2017은 시험 150장에서 AUC 0.99였으나 결핵 유사 질환 감별과 외부 기관 검증은 하지 않음. 내부 성능만으로는 실제 성능을 알 수 없음.

중규모, 외부 검증 결과는 엇갈림

3,800 ~ 6,800건

Choi 2023(3,824)은 외부에서 AUC 0.98 → 0.82 ~ 0.89로 낮아졌고, Hwang 2019(6,768, 판독의 13명 주석)는 외부 6개 데이터셋에서 0.977 이상을 유지함. 차이는 라벨 품질과 정상 대조군 규모(5.4만)였음.

대규모 다국가, 확진 기준

2.2만 명 · 10개국

Kazemzadeh 2023은 미생물 확진 기준 4개국 시험에서 영상의학과 의사와 비열등(민감도 88% · 특이도 79%). 확진 기준 성능 주장에는 다국가 규모가 쓰임.

협회 데이터의 위치

결핵 양성 4,835건은 ‘중규모’ 구간에 해당함. 이 구간에서 외부 성능을 지킨 조건은 ① 다수 판독의의 정제된 라벨, ② 충분한 정상 대조군, ③ 별도 기관의 외부 검증이었음. 협회 데이터는 ②는 확보 가능하고, ①은 판독코드 재판독으로 보완해야 하며, ③은 협회 외 데이터(협력 병원 또는 몽골 등)가 있어야 충족됨.

03모델 유형별 개발 가능성

개발 가능 (조건부)

A. 결핵 의심 영상 소견 검출

판독코드(결핵 관련 14종)를 양성, 정상 판독을 음성으로 학습함. 양성 규모는 국내 결핵 특화 연구와 같은 구간이고 음성은 충분함. 참조표준은 ‘전문가 판정’ 유형이 되므로 시험셋은 복수 전문의 재판독으로 정답을 다시 만들어야 함. 임상시험 교육에서 정한 ‘이상소견 검출 우선’ 방향과 일치함.

코드별 건수 확인 후 판단

B. 범위 · 공동 등 세부 분류

14개 코드에 경증 · 중등증 · 중증, 공동 · 공동의심, 활동성미정이 있어 세부 분류 학습 재료가 있음. 공동처럼 드문 코드가 소견당 시험 양성 약 200건을 채우는지 코드별 건수로 확인해야 함.

비활동성 코드 확인 후 판단

C. 활동성 · 비활동성 판별

연구계획서 목표 1에 해당함. 14개 코드에 비활동성(진구성) 결핵 코드가 없어 ‘그 외’에서 따로 집계해야 함. 비교 연구(Lee 2021, 6,654장)에서도 활동성 판별 외부 AUC는 0.83 ~ 0.84로 검출보다 낮았음.

현재 데이터로 어려움

D. 확진 기준 활동성 결핵 선별 (WHO 기준)

확진 기준 연구는 학습에 수천 ~ 수만 명, 시험에 수백 ~ 1천 명대의 확진자를 썼음. 협회 확진 400건은 시험셋 하나 정도의 규모라 학습까지 감당하지 못함. 해외 확진 데이터 확보 후 다음 단계 과제로 둠.

08제안하는 진행 순서

  1. 협회에 확인 요청 · 판독코드 중복 여부(코드 · 영상 · 환자 단위 건수), 코드별 건수, 비활동성 결핵 코드, 정상 판독 비율, 영상–코드 연결 방식, 메타데이터 제공 범위.
