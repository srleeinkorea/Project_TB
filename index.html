관리자 비밀번호

관리자 비밀번호를 입력하면 관리자 작업 공간(내부 검토 · 인허가 문서)과 편집 모드가 열림. 문서는 이 브라우저 안에서만 복호화됨.

편집용 GitHub 토큰 설정

문서 문구를 사이트에서 바로 고치려면 처음 한 번 토큰 등록이 필요함. 토큰은 관리자 비밀번호로 암호화되어 저장소에 보관되고, 이후에는 비밀번호만 입력하면 됨.
